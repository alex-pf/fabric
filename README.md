# Fabric

**Fabric** — AI-native фабрика разработки программных продуктов. Мета-продукт портфолио: демонстрация процесса, в котором продуктовые фичи выпускаются с минимальным вмешательством человека при гарантированном качестве.

Первый продукт фабрики — **G1**, небольшая детская игра (отдельный репозиторий).

## Состав репозитория

- `docs/journal.md` — журнал истории развития фабрики (главный артефакт проекта)
- [`docs/pipeline.md`](docs/pipeline.md) — пайплайн разработки фичи (ядро фабрики)
- `docs/decisions/` — записи принятых решений (почему выбрали тот или иной инструмент/подход)
- `pipelines/` — CI/CD-пайплайны фабрики
- `agents/` — конфигурации AI-агентов и автоматизации

## Доски

- [Fabric board](https://github.com/users/alex-pf/projects/6) — задачи по развитию инфраструктуры и процесса
- G1 board (продуктовые фичи, техдолг, баги) — создаётся на этапе запуска продукта
