# ADR-0003: Автовозобновление прерванных задач раннера

- **Статус:** принято (2026-11-25)
- **Контекст:** задача #21, обрывы продуктовых циклов по лимиту Kimi (HTTP 429)

## Контекст

Продуктовый цикл выполняет LLM-прогон (`hermes chat -q`) длительностью до часа. LLM-провайдер имеет 5-часовые окна квоты: исчерпание (429) убивает прогон посреди работы — карточка остаётся в In Progress, ветка/черновик — в рабочем клоне. Watchdog брал задачи только из Todo, поэтому прерванная задача не возобновлялась никогда: требовался ручной подхват по runner-ops. Обрыв по квоте — штатное, регулярное явление, а не эксепшн.

Дополнительно `subprocess.run` не проверял результат прогона: смерть цикла была невидимой в логах тика.

## Решение

1. **Requeue**: карточка в In Progress при свободном локе (живого прогона нет — иначе тик не получил бы лок) считается прерванной и возвращается в Todo. Дальше — штатный путь через `todo[0]`. Cooldown 30 минут на карточку против дёрганья туда-сюда.
2. **Resume-протокол в промпте цикла**: рабочая папка `/opt/data/cache/scratch/<repo>-<N>`; существующая ветка `feature/<N>-*` (локально или на origin) продолжается, а не пересоздаётся; существующий PR не дублируется — доводятся checks и карточка в Need Review.
3. **Backoff по квоте**: маркеры лимита в выводе прогона → `quota_until` (+30 мин), старты циклов на паузе, попытка возобновления НЕ расходуется. После сброса окна провайдера задачи продолжаются сами.
4. **Cap попыток**: 10 возобновлений одной карточки безуспешно → паркинг (остаётся в In Progress) + комментарий в issue «нужен человек».
5. **Состояние**: `resume-state.json` на томе (переживает пересоздание контейнера); `WATCHDOG_DRY_RUN=1` — проверка логики без побочных эффектов; вывод прогона (хвост) и код возврата пишутся в лог тика.

## Альтернативы

- **Resume in-place** (отдельный путь обработки In Progress без возврата в Todo): две точки входа цикла, очередь для человека перестаёт быть честной. Отвергнуто — Todo остаётся единственной точкой входа.
- **Бесконечные ретраи без cap**: системная ошибка в задаче крутилась бы вечно, сжигая квоту LLM. Отвергнуто — паркинг с комментарием.
- **Sleep до конца окна квоты внутри тика**: cron-скрипт не должен спать часами и держать лок. Отвергнуто — пауза через состояние между тиками.

## Последствия

- Ручной подхват (references/runner-ops.md) остаётся запасным путём, штатно не нужен.
- Состояние попыток/паркинга прозрачно: `resume-state.json`; сброс паркинга — удалением карточки из `cards` (или возвратом карточки человеком в Todo).
- Парковка карточки — сигнал человеку через комментарий в issue, а не молчаливое зависание.
